# AI 裁判验收

2026-10-29，用户明确指定由当前助手验收并评分。该要求补充原人工金标路线：缺人工转录不再阻塞AI质量验收；既有未测、失败和原始响应继续保留。

## 规则

- 依据同一原图先建立独立参考，再读取匿名候选输出；候选标签逐页独立随机化，映射仅保存在私有目录。不可按模型身份调门槛。
- 所有结果明确标注AI裁判；不得将AI转写或判断写成human_verified。
- 完整性与忠实识别40分、字符/关键符号正确性30分、适用结构与阅读顺序20分、幻觉与无依据改写10分。无适用结构时在预定任务权重内重新归一化，不能因模型缺能力而改为不适用。
- 保留CER/WER、表格、公式、块覆盖和阅读序等可计算指标，AI分数与客观指标并列；速度/资源单独比较，不用一次加权总分抹平关键漏字或结构缺口。
- 验收门与100分并列：关键字段误识、整行遗漏、输出截断、身份/资源错配或无依据事实新增均判该任务验收FAIL；高平均分不能抵消。失败仍按原四维记分，不人为调低分数制造结果。
- 关键错误、整行遗漏、截断、身份/资源错配一律列出。原图存疑处记录坐标、候选字和置信度，不擅自补成确定参考。
- 精确字符指标只对已完成独立视觉核对的参考计分，报告覆盖率；未核对部分仍UNSCORED。全输入仍执行状态/结构/产物检查，不把抽样验收冒充全字核对。

## 盲评前冻结的判分锚点

本规则在裁判读取候选识别文字前冻结。总分至少90且没有上述否决项，才可在已审范围标记`AI_ACCEPTED`；80–89为`AI_REVIEW_REQUIRED`，低于80为`AI_REJECTED`。任一否决项均标记`AI_REJECTED`，同时保留原始四维分数。源图不可辨认或必要范围未审时为`UNSCORED`，不能以零分或通过替代。

| 分项 | 共同判分锚点 |
|---|---|
| 忠实与完整，40 | 40：内容完整；35：少量局部遗漏；25：明显短段/整行遗漏；10：大量内容缺失；0：空输出或主要内容缺失。按具体证据可在锚点之间取整数。整行遗漏同时触发否决。 |
| 字符与符号，30 | 30：未见错误；28：少量非关键字符；25：多处局部错误；20：反复错字或重要符号错误；10：大面积误识；0：无法使用。精确CER另列，存疑源字不强判。 |
| 结构与阅读序，20 | 20：适用版式/行序/表格/公式完整；15：局部格式偏差；10：可恢复的阅读序或结构损失；5：严重错序/结构丢失；0：适用结构不可用。 |
| 幻觉与改写，10 | 10：无依据新增为零；8：少量规范化改写；5：多处无依据改写；0：明显编造。无依据事实新增同时触发否决，原稿病句和错字不应擅自修正。 |

先独立记录A/B四维分数、错误坐标/引文、审阅范围和否决理由，再解盲。不根据对方表现调整分数。全页、手写正文、确定姓名/印章、表格/公式、合成控制、扰动各自汇总，重复扰动不能当作新增独立源样本。
