## 三条路线，不混账

1. **F：原冻结合同。** Flash-Next GSQ-RCO IQ3_XXS 混合包、INT8 KV、既定单会话 Pi/Java 目标。最新有效状态仍是 `NO_QUALIFIED_CANDIDATE`；六项长检索 FAIL 与 P05 `BLOCKED_EVIDENCE` 保留。
2. **T：目标分布不变的草稿 / 调度研究。** MTP 词表、单独 COUPLED、长 Lookup、新草稿服务路径等。不是天然 E0；要证明采样、验证、回滚以及自然执行的数值行为，且先证明真实负载覆盖。
3. **Q：独立质量—性能前沿。** HC_Q8、k8v4、q4_0。可以改变数值，不属于“同精度无损提速”；需另行批准可接受质量损失和实验范围。本文不替用户批准这项取舍。

冷读 / 长追加 Prefill 是独立目标合同，不能在 warm Decode 失败后临时换主指标。

## 已核对的几个关键事实

- 10 月 23 日之后的实验主线已是 **IQ3_XXS**；早期 IQ3_S / 75.1 tok/s 不是当前统一基线。
- 5060 Ti Gist 只有 1776 字节配置，未提供原始 benchmark；路径也全部为 IQ3_XXS。
- `cache 6144 MiB / 4 slots` 是**总预算 6144 MiB**，不是 24 GiB。
