# P11｜全局草稿archive、选择、异步staging与图

在ringDFlash2的正确性、预算和基线测量已通过后，推进全局检索；ring尚无默认采用收益不阻断该实验。

前置：P10-GATE。基准：该gate的真实qualifiedcommit；T为参考源码，不是本phase merge parent。所有任务PENDING。

## Task与并行关系

| Task | 成果 | 依赖 | Owner |
|---|---|---|---|
| P11-T01 | 独立ProjectedG host archive和版本化identity | P10-GATE | Archive worker |
| P11-T02 | 全局页代表索引与两级CPU oracle | P10-GATE | Index worker |
| P11-T03 | GPU coarse/refine选择、按headstage与Draft位置映射 | P11-T01, P11-T02 | CUDA worker |
| P11-T04 | 图外异步刷新、双stage和迟到任务隔离 | P11-T03 | Runtime worker |
| P11-T05 | 连接continuation、重写、slot与adapter生命周期 | P11-T01, P11-T04 | Integrator |
| P11-T06 | 检索成本进入后端策略与观测 | P11-T05 | Telemetry + Policy worker |
| P11-T07 | 全局检索128K/248K远端依赖与端到端资格 | P11-T06 | Evaluation owner |


`depends_on`不同且文件owner不冲突时可并行。CMake、public headers、schedule/Program集成串行；GPU作业由唯一队列调度。phase gate读取组合后的一个sourcecommit，不拼接worker独立结果。
