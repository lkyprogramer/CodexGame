# P9｜已有完整KV验证的瓶颈优化

不裁剪Targetcontext，以有证据的热点选择最小算子/图优化。

前置：P8-GATE。基准：该gate的真实qualifiedcommit；T为参考源码，不是本phase merge parent。所有任务PENDING。

## Task与并行关系

| Task | 成果 | 依赖 | Owner |
|---|---|---|---|
| P9-T01 | 固定完整验证数值oracle与优化点 | P8-GATE | Numerics worker |
| P9-T02 | 优化选定full-KV kernel或保持现状 | P9-T01 | CUDA worker |
| P9-T03 | 冻结verify图包络和资源生命周期 | P9-T02 | Runtime worker |
| P9-T04 | 完整验证优化的长上下文资格 | P9-T03 | Evaluation owner |


`depends_on`不同且文件owner不冲突时可并行。CMake、public headers、schedule/Program集成串行；GPU作业由唯一队列调度。phase gate读取组合后的一个sourcecommit，不拼接worker独立结果。
