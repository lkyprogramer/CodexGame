# CFG-SPECCOST（v2 O33）：`STRATA_SPEC_COST=1`（2026-10-26）

**结论：NO_BENEFIT，不采用，保持 `--spec-min-p 0.5` 的阈值规则。**

开启后，成本规则把 MTP 窗口剪短了：回答段平均 T 3.43 → 3.05，每窗口 19.74 → 18.27 ms。但每窗口提交的 token 同比例下降（2.86 → 2.63），每 token 成本基本不变。配对结果：

| 组 | 配对中位 [95% CI] |
|---|---|
| 思考段 | 1.003 [0.987, 1.028] |
| 回答段 | 0.991 [0.972, 1.030] |
| 长 decode | 0.977 [0.943, 1.020] |
| 短 greedy | 0.973 [0.913, 1.006] |

这与 CFG-SPEC-S 的结论一致：在 29 上，T=3～5 每提交一个 token 的成本基本持平。窗口宽度怎么调（固定 `--spec`、`--spec-min-p` 阈值，还是成本规则），都只在这条平线上移动。
