# Strata v0.2.10 PT0 与生产版本配对（2026-11-04）

**结论。保留 Qwen Next v0.2.3 生产版本，暂不移植 #1536。** v0.2.10 的冷读首字延迟中位改善 2.7%。同输入的 Java LSP 暖态生成速度下降 14.5%。两版的两轮任务通过率均为 0/3，质量非劣未验证。原 v0.2.3 已恢复，生产入口冒烟通过。

## PT0 适配和 CPU 验证

- 隔离复制 Control 0.1.56 的 `serve`。只在 `serve/frontend.py` 的 OpenAI 请求入口增加八行。模板继续用现有 IQ3_XXS 模型资产。
- 显式布尔 `chat_template_kwargs.preserve_thinking` 优先。未指定有效布尔值时，思考开启的请求读取 `STRATA_PRESERVE_THINKING=0/1`。环境变量未设置时使用模板默认值。PT0 表示去掉已完成轮次的历史思考文本。
- `seed43` 的同一历史请求在默认 PT0、显式 false、无效值回落 PT0 时均为 4,408 token。默认 PT1、模板默认、显式 true 均为 44,108 token。六项的 token 序列在两版逐项相同。另核对思考关闭且无显式 PT 覆盖时的参数。
- 两条 Pi 投影的冷读和保存续写均在两版逐 token 一致。Java LSP 的冷读为 78,701 token，保存续写为 84,342 token。NSO 的冷读为 98,001 token，保存续写为 98,268 token。启用各自的 PromptEncoder 后，两版均复现各自的完整冷读前缀。运行时复用量另由引擎计数验证。

## 对照设置

29 的 RTX 4090 上串行执行三组配对。顺序为 Java LSP A/B、NSO B/A、NSO A/B。NSO 是同一会话的重复观测。共 6 次引擎启动和 12 次模型请求。每次引擎启动后先冷读，再立即追加该轮工具调用的实际返回。两版共用冻结的代码文件和白名单。原评分器在隔离 Docker 中运行提交的代码。

A 使用生产 A0 v0.2.3 二进制和生产 reply/PT0 语义。B 使用 v0.2.10 Control 0.1.56 和本机 CUDA 12.3 隔离引擎，保留此前的会话 K/V 正确性修补。本轮只增加 PT0 适配。A 的 #1536 已启用，B 使用上游复用逻辑。HC 补丁跳过。

两版均为 IQ3_XXS、128K、单槽 MTP spec4、`--spec-min-p 0.5`、INT8 KV、`--kv-resident 20480`。会话缓存预算为 6,144 MiB / 4 槽。显存预留 974 MiB。专家缓存自动分配，A 为 10,293 槽，B 为 10,118 槽。两版关闭后缀草稿。B 另传 `--lookup-max-t 0`，A 无独立选项。三组均观测到实际 MTP 草稿。

- **生产选择。** 冷读首字延迟的三组改善为 1.45%、2.81%、2.74%。Java LSP 的两版工具返回内容相同，暖态整轮耗时增加 15.4%。NSO 的工具返回为 799 → 1,431 字节，两组暖态首字延迟包含不同输入长度。样本量和任务结果不足以支持生产切换。
- **#1536。** Java LSP 两版都复用全部冷读前缀和 43 个上一轮生成 token。两组 NSO 均复用全部冷读前缀，且额外复用由 56 增至 65 个 token。暖态新增读量的差异出现在工具返回内容变化的 NSO 组。两条会话均未观察到 B 的复用损失，因此暂不移植。这个结论限于本次两条会话和实际生成路径。
- **质量。** 两版首轮工具调用均通过白名单检查（各 3/3）。Java LSP 的两版输出均未通过原评分器，分别为 `SyntaxError: Unexpected token '<'` 和 `SyntaxError: Unexpected identifier 'at'`。NSO 四次暖态均再次发起工具调用，未提交最终代码。预算内不发第三轮，计入两轮任务失败。两版均为 0/3。
