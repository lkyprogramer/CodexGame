## 1. 证据、收益与适用性

**来源报告：** 作者Host memcpy微基准新分配5.19～7.17GB/s，重用17.47～17.85GB/s；不是GPU→Host也不是tok/s。实际AMD测试只有短会话，CUDA/Linux端到端未验证。 [来源](https://github.com/Niko1221/Strata/pull/3711)

**本机判断：** 前提在 29 生产上**已成立**：6144 MiB × 4 slots，10-12 parking 45 次 / restore 7 次。10-15 起 parking 因 MemAvailable 约 1.5 GB 被拒，驱逐后 MemAvailable 不回升、进程 `[heap]` 约 6.9 GB——推断与 Host KV 缓冲反复分配/释放后的 glibc 堆保留有关，**未验证**。**2026-10-23 修订**：#2253 给出了该现象的直接根因——16 MiB 分段在 glibc 动态 mmap 阈值抬高后来自主堆，释放后不归还系统；29 日志中 12 次拒绝有 11 次发生在缓存已空时。本项**有意保留**页面以减少缺页，方向与 #2253 / CFG-MMAP 相反，因此从第 4 降到第 8：只有在 #2253 或 CFG-MMAP 让内存有界之后，才评估页复用能否在设定上限内降低 capture 成本。保留页本身会增加RSS，必须设置回收上限。

收益数字不是本包作者4090实测，也不作为验收预设答案。先证明瓶颈存在，然后决定是否继续。

## 3. Phase / Task

### Phase A：机制资格与最小设计

A1：运行doctor与qualify；保存模型、KV、MTP、缓存、CPU/PCIe和内存证据。A2：构造能反映该机制的最小样本，确认不是不相关瓶颈。A3：冻结主指标、off/on语义和资源状态图。**Review Gate A**：条件不成立就NOT_APPLICABLE，不先写大改。

### Phase B：最小移植

- B1：保留donor最深checkpoint仍有效的guard；不能仅Token IDs相同就认定KV相同。unchanged_tokens继续为0。
- B2：slot image与park donor复用分别实现，可独立测；空闲内存低时清理保留segment。
- B3：原STRATA_SLOT_SHUTTLE=0仅关闭slot复用，不能当全PR off；新增STRATA_LAB_WARM_PAGES master覆盖全部改动。
- B4：保留最新main的异步copy stream生命周期，不把一个buffer复用到仍在DMA的路径。

**Review Gate B**：至少检查主线程/worker、异步copy、缓存身份、取消错误恢复和默认关闭路径。可以并行进行文档/CPU测试审查，但GPU实验只能串行。

### Phase C：失败测试与正确性

- C1：allocation failure、short→long→short、donor受保护、不同model/position、cancel/free幂等。
- C2：CPU memcpy microbench只用于机制确认；故意反复复用后校验整buffer字节。
- C3：MADV_HUGEPAGE失败是可退化，不是成功证明。

要求在未修改A0或关闭路径上看到机制测试失败（对于纯性能优化使用已固定的性能断言/dispatch断言），在候选中通过。不能把缺失测试数据导致的skip计为pass。

### Phase D：实机A/B

- D1：一张4090，顺序A→B→A会话（不为了PR额外开batch）；有parking才测试。cache profile 用生产形态 6144 MiB × 4 slots（前提是加载后 MemAvailable 门槛成立），主指标是 N 轮 park/restore/evict 后的 RSS、`[heap]` 大小与 MemAvailable 曲线，tok/s 为次要指标。
- D2：测真实D2H/H2D与capture/restore，区分metadata restore和大块copy。
- D3：重复200次小会话后返回长会话，RSS保留量不能无界增长。

**必须观察到的机制回执：** 减少fresh-page faults和capture成本，但保留字节上限明确。

**停止条件：** 当前没有parking、只有Host memcpy变快而任务不变、内存持续增长或未完成DMA就复用时停止。

### Phase E：留出与结论

E1：同一Java mini-agent题集与真实Pi留出任务。E2：按统计协议产出CI、质量、资源与回退报告。E3：写DECISION.md并保留最小补丁。**Review Gate E**：只有经过独立留出验证才能推荐生产，脚本不会自动切换。
