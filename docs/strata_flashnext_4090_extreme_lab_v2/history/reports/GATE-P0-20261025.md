## 4. 已知限制

- 全部是受控 HTTP 回放、单请求串行：没有真实 Pi 流量、没有并发，也没有 park / restore 多轮会话（#2253 Phase 补）。
- greedy 输出跨进程不可复现（同一配置 35 次只有 6 次文本一致）。所有“输出一致”类门槛改用质量组判定；PR 文档里依赖逐位一致的机制测试，要在源码级（kernel parity）做，不能靠 HTTP 文本比对。
- `perf` 不可用：CPU 侧计算 / 同步 / TLB 的占比没有拆，NP-3 / NP-1 只能用代码实验加窗口 trace 判断。
- Java 组 NOT_RUN（29 没有 Docker JDK 镜像）。
