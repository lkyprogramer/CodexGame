# P0-T2b 报告：P→A0 迁移评估（MIG）（2026-10-25）

**结论：MIG-PASS。** 在同一份生产配置、同一组负载下，A0（v0.2.3，引擎 0.1.48）和 P（生产 0.1.43.1）的 prefill、decode、TTFT 和质量都在噪声内持平：

- 各组配对比值（A0/P）的中位数在 0.97～1.02 之间，没有任何一项比 P 差超过 5%；
- 引擎每窗口耗时 18.38 对 18.36 ms。

按文档的分支规则，后续所有配置对照和 PR 实验都在 A0 上做，P 上不重复测。生产升级到 A0 是单独的变更，需要你另行审批；本轮没有动生产。

## 6. 限制与未覆盖

- 题集是受控的 HTTP 回放，不是真实 Pi 流量。long-retrieval / cold-prefill 的输出只有约 139 token（模型答完就停），所以长上下文的 decode 样本较短；固定 512 输出只在短 prompt 的 decode 组成立。
- park / restore 多轮切换场景没有覆盖（实验包没有内置），放到 #2253 的 Phase 里补。
- `STRATA_PREFILL_CPU_SHARE_MAX=3072` 是否生效，日志看不出来。两边读同一个变量名，结果一致，不影响 MIG 结论；P0-T5 DIAG 时再核对。
- 采样组 decode 的 CI 较宽（[0.913, 1.004]）：采样输出跨进程不可复现，配对噪声约 7%，与 02_ENVIRONMENT 记录的一致。
