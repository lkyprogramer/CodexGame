# lower-bound

Implement Java 8-compatible public class Solution, with no package declaration. Output Java code only, no markdown or explanation. Do not access files, network, processes, reflection or environment. Provide public static int lowerBound(int[] a,int x), returning the smallest index i where a[i]>=x in ascending a, or a.length if none. Null input throws IllegalArgumentException. O(log n), no mutation.
