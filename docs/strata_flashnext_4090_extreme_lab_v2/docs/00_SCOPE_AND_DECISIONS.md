# 设计总纲：Flash-Next / 4090 极限优化实验室 v2

研究截面：2026-10-25。交付对象是可供 AI 继续实施的设计、任务、验收工具与证据规范；本轮未连接目标机、未修改 Strata 引擎、未进行新的 GPU 实测。

## 1. 成功定义

目标是在用户现有单张 RTX4090、64GB RAM、Xeon Silver4216 与现有 Flash-Next 模型上，提高**正确完成一轮真实 Java 编程任务的速度**，同时改善可复用前缀、长上下文及多会话的性能。以当前已部署 A0+EXACT6 为历史基线，以最新固定源码为后续开发基线。

“极限”意味着深入所有主要资源路径：请求与缓存、speculation、CPU expert、GPU kernel、CPU/GPU分工、PCIe、显存/主存、数值格式和编译。它不意味着每个理论方向都应合并，也不意味着允许把输出变短、丢专家、降低上下文或减少质量来伪造等价提速。

主指标采用预登记任务预算B下的 restricted time-to-success：成功记实际完成wall，未成功记B；完成率另设质量门。不能只平均成功请求或两臂都成功的交集。详见统计协议。

## 2. 已确定的约束

- GPU：单张 RTX4090，sm_89，24GB；主机64GB。
- CPU：Xeon Silver4216，16C/32T，DDR4两条；历史读带宽约36GB/s。
- 模型：Flash-Next GSQ-RCO IQ3_XXS；文件名不等于每个tensor的量化类型。
- 总上下文上限：131072 token，包含模板、system、tools、历史、输入及输出；普通长测额外保留4096 token余量。
- 保留当前权重、tokenizer、chat template、MTP与真实Pi请求语义作为第一条主线。
- 当前生产端口18343及NGINX28343不用于自动实验；实验端口18089。
- 所有新引擎改动默认关闭。候选只在隔离源码树和独立结果目录中运行。
- 不以未合并PR、不同GPU上的token/s或仅编译成功作为本机性能证据。
- 此包不含新的推理引擎补丁；包含验证工具修复与后续引擎改造任务。

## 3. 方案选择

| 方案 | 价值 | 成本与问题 | 决定 |
|---|---|---|---|
| 改用其他引擎整体替代 | 可获得特定实现 | 模型/量化/状态不匹配，失去现有已验证路径 | 不作为主线 |
| 批量合并所有性能PR | 快速扩展功能 | 混合变量、互斥路径、收益无法归因 | 不采用 |
| 在最新Strata上建立独立候选，按真实瓶颈移植机制 | 保留现有资产；允许深入kernel；可归因和回退 | 需要测量、数值门和分阶段验证 | **本包采用** |

## 4. 三条主实验轨道与X旁路

1. **E：实现等价轨道。** 任务切分、缓存生命周期、拷贝组织、相同数值路径的融合。优先维持同一输入下逐位输出；若因合法舍入变化无法逐位一致，应降为N，不冒充E。
2. **N：数值路径变化轨道。** 新归约、ISA路径、GDN chunk、改变CPU/GPU执行位置、KV或权重精度。公式或模型意图可相同，但需要teacher-forced、长轨迹和任务非劣验证。
3. **Q：模型/请求语义变化轨道。** 专家延后/裁剪、稀疏预算变更、激活近似、上下文压缩、其他权重版本。单独报告质量与速度，不进入E/N的合并提速。

GPU解锁归入X实验轨道：不是普通用户态补丁，默认不执行；先证明目标工作负载确实受相关Tensor指令发射限制。

## 5. 执行授权边界

用户本轮要求的是完整文档与可验证实验体系。文档允许后续AI在已授权的隔离实验环境实施；不代表本轮已经修改用户机器。启动实验前由本机执行者核对维护窗口、服务所有权、剩余资源和配置身份。既有授权可复用，不要重复要求批准已批准的只读检查或实验；遇到会停现网、改启动链、清理未知数据等超出已知授权的动作再暂停。

## 6. 资源与交付原则

一张GPU只运行一个性能实验；CPU微基准不与GPU测量并行。允许多agent并行阅读、开发和CPU测试，GPU通过统一锁串行。阶段结束必须留 source/build/config/assets/dataset/host 的身份、原始日志、失败记录与可重算统计。任何未满足的门返回 BLOCKED 或 INSUFFICIENT，不返回PASS。

## 7. 范围的完整性

方向图谱按完整数据流逐段展开，共64项优化方向及6项前置工作。它覆盖本硬件/模型约束下可识别的主要理论空间，不能证明未来不存在新算法。研究型方向有先导实验和晋级条件；多卡、NVLink、Hopper TMA、Blackwell原生NVFP4、AMX等不满足硬件前提的路线列入排除表，不伪装成本机可执行方案。
