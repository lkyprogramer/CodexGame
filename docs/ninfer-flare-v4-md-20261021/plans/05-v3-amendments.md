# 对历史任务的权威覆盖

1. 完整P0/P6、全上游U34、多协议/图像/UI验收不阻挡性能开发；复用P4研究身份及对应证据。
2. 保留已集成上游性能改动，剩余改动按纯Chat可达性/性能假设/必要耦合选择；完整合并是可选candidate，不是统一前置。
3. correction独有oracle只约束correction。kernel、workspace、Lookup和高级草稿路线可独立选择，不重复构建已有算子/观测框架。
4. W8/W16、DFlash2、全局检索、utility有性能可能，保留实际任务与scope；只取消强制串行与无证据的全组合验证。W16→W8等真正技术依赖继续保留。
5. 数值、Target分布/RNG、正式state/许可、Graph最后consumer、缓存身份/容量和故障仍是选中改动的必要验收，不能以“只做性能”删除。
6. 每个选中候选只做一次共同K4资格；生产K4-GATE独立且需以后明确授权。当前原GPU服务保持停止。
7. 旧Baseline/编程题/grader/已过任务不重跑，全部失败/拒绝/成本和缺失附件保留。新验证只针对新路径或新科学主张。
