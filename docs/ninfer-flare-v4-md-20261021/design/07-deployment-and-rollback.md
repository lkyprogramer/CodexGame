# 生产发布独立门禁

当前所有candidate scope只给隔离研发/验收计划，不发布生产。K4-QUALIFIED达到前不能宣称可上线；达到后仍需用户明确授权生产操作。完整上游合并、构建成功或局部GPU PASS都不能替代发布证据。

未来K4-GATE记录明确目标镜像/argv/model/codec/cache身份、候选适用范围、准备好的回退工件与实际发布/回退验证。原缓存目录与镜像保留，不在新格式验证中覆盖。原始失败、18处G1差异、C1与Baseline证据缺口全部披露。

用户当前要求原GPU服务持续停止，因此本轮和后续候选清理都不自动恢复。若以后要求上线，应按新授权决定服务交还状态，而不是机械沿用此前“恢复原服务”的历史脚本。
