# T04 · 增加共享编码的可选 restart trace

**Scope：B0+B1 首期 · 初始状态 NOT_RUN**  
**依赖：** T03  
**关联门：** G1, G2


**文件：** tokenizer.h/.cpp及trace测试；不改B1产品接线。  
**输入：** B0 encode_impl；EncodingRestart/TracedEncoding。  
**输出：** encode_traced与同一encode_impl，真实added结束点，request-local计数。

- [ ] 先红test要求trace初始(0,0)、实际added结束点递增；普通EOF不成为restart。
- [ ] 同一input的encode和encode_traced.token_ids相同；parsefalse时只有初始restart，空input不丢起点。
- [ ] 记录点在added ID push后，token_end=ids.size()；局部ordinary分段执行仍原样。

```cpp
if (trace) trace->push_back({0, 0});
// After the selected added token has been emitted:
ids.push_back(match->id);
pos = match_pos + match->content.size();
if (trace) trace->push_back({pos, ids.size()});
```

- [ ] trace禁用路径不分配vector，避免count_tokens支付无用开销；test检查不会调用另一个复制scanner。
- [ ] 对每个短input全部bytecut计算r<=b，验证r对应实际已选token，不从text.find标记恢复。
- [ ] 与legacy独立编码R[:b]比较局部分解，UTF8切点异常也比对；这里只验证分解，不改错误contract包装。

**验收：** trace可用于03定理；结构单调、无共享可变状态。  
**停止：** 把任意token/ordinaryEOF加入restart、trace影响原tokens。  
**提交：** `feat(frontend): expose request-local selected-token restart trace`。
