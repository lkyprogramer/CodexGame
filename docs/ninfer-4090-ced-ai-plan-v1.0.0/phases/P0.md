# P0：冻结基线、资源预检与实验护栏 — Implementation Plan

> For agentic workers：按任务依赖执行；有相应技能时使用 subagent-driven-development / executing-plans。没有该技能也必须遵守本包的Phase Gate与证据要求。不要在本Phase末前重复运行全量长测。

**Goal：** 建立可归因、可恢复、单GPU串行的实验基座。

**Architecture：** 复用NInfer已有Program、层调度、KV/GDN状态和speculative事务；新增代码按02/03明确的职责进入，不复制引擎。

**Tech Stack：** C++20 / CUDA13.2开发容器 / sm_89 / Python离线工具；训练使用固定PyTorch环境，base权重不变。

**Spec：** [架构](../docs/02-architecture.md)、[状态接口](../docs/03-contracts.md)、[测试合同](../docs/05-verification.md)。

## 进入条件

用户后续明确授权执行；CPU工作无需停生产。

## Global Constraints

[AGENTS.md](../AGENTS.md)与[生产保护](../docs/07-operations.md)全部约束适用于每个Task。`NEW`为待创建；`MOD`为已有文件；`@source_map`是P0已解析文件；`ced-research/`相对LAB_ROOT，其余源码路径相对candidate repo。测试源文件要同步注册到CMake或suite manifest，不得仅创建而不运行。

**执行时点约定：** 下文Task中的完整矩阵、性能重复和质量campaign，是该Task要实现并注册的验收能力，统一在本Phase Gate执行，不在每个Task结束后重复跑。Task局部只做编译、契约单测和必要小fixture；Teacher导出/训练是开发工作本身，可以依赖顺序执行，但不替代Phase统一验证。P7-T02/T04分别是两个子阶段的统一Gate。
