# P8：默认关闭的交付、恢复演练与报告 — Implementation Plan

> For agentic workers：按任务依赖执行；有相应技能时使用 subagent-driven-development / executing-plans。没有该技能也必须遵守本包的Phase Gate与证据要求。不要在本Phase末前重复运行全量长测。

**Goal：** 交付最高合格实验档及可复现证据，保持生产配置不被暗改。

**Architecture：** 复用NInfer已有Program、层调度、KV/GDN状态和speculative事务；新增代码按02/03明确的职责进入，不复制引擎。

**Tech Stack：** C++20 / CUDA13.2开发容器 / sm_89 / Python离线工具；训练使用固定PyTorch环境，base权重不变。

**Spec：** [架构](../docs/02-architecture.md)、[状态接口](../docs/03-contracts.md)、[测试合同](../docs/05-verification.md)。
