## 反例与验收断言

1. 用假的artifact SHA必须拒绝后续GPU阶段
2. 无法解析donor SHA不能改为main
3. driver/UMD与nvcc分列
4. GitHub断开时明确fallback，不清缓存重装
5. memory-ledger对262144必须给出负余量；把文件差19.03−16.96直接当resident delta的输入必须被标记而非接受
