## 反例与验收断言

1. d256全dot后单softmax；split128错误负对照必须失败
2. prefix!=0且qolen!=kvlen，mask边界准确
3. >2GiB stride不溢出；所有maskedkey不贡献
4. 新numericvariant质量不能借原target3/3
