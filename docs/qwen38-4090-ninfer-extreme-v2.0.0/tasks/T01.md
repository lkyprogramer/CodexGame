## 反例与验收断言

1. ready=false或缺command/evidence必须在停生产前失败
2. SSH断开，远端90s心跳/TTL触发恢复
3. 不能stop陌生容器或其他unit
4. tools HTTP response有真实tool_calls，未支持strict时显式4xx
5. 容器被绕过systemd删除（unit仍active、18343开、18030关）时健康检查必须失败
