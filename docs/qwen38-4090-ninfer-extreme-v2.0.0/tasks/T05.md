## 反例与验收断言

1. 重复128token、全新随机token、空prefix、接近200192
2. 强制hash碰撞时比较真实tokens
3. A/B sessions互不命中；rewind后不能读旧future
4. 结束的reference答案没有ingest入口
5. 查询含未提交草稿时，命中返回的继续必须来自草稿之前的历史，且草稿被拒后索引状态不变
