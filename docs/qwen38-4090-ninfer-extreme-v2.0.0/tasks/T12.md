# T12 — W16 packed4 decode优化

**依赖**：T07, T06。**路线**：kernel。**初始状态**：NOT_STARTED。

## 范围与接口

输入d256、24Q/4KV、packed4、W16/liveQ；输出同数学的独立querysoftmax和splitpartials。W16对suffix copy/rewrite（T06 v1上限W=6）同样有价值且不需要新权重，因此依赖是T07（合法宽路径）+T06（命中率证据），**不依赖DFlash2完成**；DFlash2若被T07门否决，本任务仍可进行。

读取设计：`../docs/03-architecture-and-state.md`、`../docs/05-exact-sampling.md`、本路线专题文档。

## 反例与验收断言

1. mask满足key_abs<=prefix+row，不允许未来列
2. 独立softmax每row，不按两个128半头做softmax
3. 64bit地址边界与页乱序
4. ncu诊断不混进ABBA计时
