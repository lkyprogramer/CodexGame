# 12 · 私有项目回放扩展

公开题库适合统一横评，但最终部署决策应加入 10–30 个私有真实任务，尤其是你的 Java 仓库：调用链定位、Spring API 变更、Maven/Gradle 修复、多模块重构、测试失败修复和配置迁移。

## 构建方法

1. 从已解决 issue/commit 中抽取任务；
2. checkout 缺陷前 commit 作为 workspace；
3. 把原 commit 的测试或新增回归测试作为 hidden verifier；
4. 清除 issue 文本中的答案线索；
5. 记录真实人工解决时间和修改范围；
6. 保持私有，不上传到公开仓库或模型对话历史。

## 统计

私有集不与公开集简单合并。单独报告方向一致性：公开集胜者是否在私有 Java 任务上仍保持成功率、耗时和错误编辑优势。

## 隐私

删除凭据、客户数据、内部域名和个人信息。执行模型前使用离线副本，禁止工具访问生产网络和真实密钥。
