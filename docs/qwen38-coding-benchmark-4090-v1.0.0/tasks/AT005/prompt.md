# 定位 SQL Migration 分句错误

你正在维护一个仅使用 JDK 标准库的 Java 17+ 小型工程。请在仓库内完成修复或实现。

## 任务

公开测试显示 SQL 字符串中的分号被错误拆分。修复 migration 分句器：只在普通代码状态下以 `;` 分句；忽略单引号字符串（支持 `''`）、双引号标识符（支持 `""`）、`--` 行注释和 `/* */` 块注释中的分号；空语句丢弃、结果不可修改；未闭合引号或块注释抛出 `IllegalArgumentException`。

## 约束

- 不引入第三方依赖。
- 保持现有公开类名和方法签名，除非题面明确允许调整。
- 处理边界条件、异常语义和并发要求。
- 只修改必要文件；不要读取或猜测隐藏测试。
- 可用工具时先检查 整个仓库并运行 `python3 public_tests.py`，完成后运行公开测试（若存在）。
- 最终修改必须留在工作区；非工具模式下输出统一 diff。
