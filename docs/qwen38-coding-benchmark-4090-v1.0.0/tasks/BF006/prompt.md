# 修复命名 SQL 参数编译器

你正在维护一个只依赖 Python 3.11+ 标准库的工程。请在仓库内完成修复或实现。

## 任务

修复 `compile_named(sql, params)`，把 SQL 中的 `:name` 替换为 `?`，并按出现顺序返回参数列表。重复占位符必须重复加入值。不得识别单引号字符串、双引号标识符、`--` 行注释、`/* ... */` 块注释中的冒号；PostgreSQL `::` 类型转换也不是参数。参数名为 `[A-Za-z_][A-Za-z0-9_]*`。缺失参数抛出 `KeyError`，未闭合字符串或块注释抛出 `ValueError`。

## 约束

- 不引入第三方依赖。
- 保持现有公开 API，除非题面明确允许调整。
- 考虑输入校验、边界条件和确定性行为。
- 只修改必要文件；不要读取或猜测隐藏测试。
- 可用工具时先检查 仓库中的 Python 源码，完成后运行公开测试（若存在）。
- 最终修改必须留在工作区；非工具模式下输出统一 diff。
