# 确定性拓扑分层

你正在维护一个只依赖 Python 3.11+ 标准库的工程。请在仓库内完成修复或实现。

## 任务

实现 `topological_layers(graph)`。`graph` 是 `节点 -> 依赖节点集合` 的映射。

返回列表，每个元素是同一层可并行执行的节点列表；层内按节点字符串字典序排序。所有依赖节点都必须显式出现在 graph 的 key 中，否则抛出 `ValueError`。存在环时抛出 `ValueError`，错误消息中至少包含所有仍在环或受环阻塞的节点名称。输入不得被修改。

## 约束

- 不引入第三方依赖。
- 保持现有公开 API，除非题面明确允许调整。
- 考虑输入校验、边界条件和确定性行为。
- 只修改必要文件；不要读取或猜测隐藏测试。
- 可用工具时先检查 仓库中的 Python 源码，完成后运行公开测试（若存在）。
- 最终修改必须留在工作区；非工具模式下输出统一 diff。
