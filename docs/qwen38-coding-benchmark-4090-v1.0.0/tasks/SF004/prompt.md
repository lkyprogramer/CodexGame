# 区间合并与接触策略

你正在维护一个只依赖 Python 3.11+ 标准库的工程。请在仓库内完成修复或实现。

## 任务

实现 `merge_intervals(intervals, *, merge_touching=False)`。

输入是 `(start, end)` 二元组迭代器，输出按起点升序排列的新列表。重叠区间必须合并；仅在 `merge_touching=True` 时合并首尾刚好相接的区间。允许整数和有限浮点数，拒绝布尔值、NaN、无穷、非二元组和 `start > end`，统一抛出 `ValueError`。不得修改调用者传入的列表。

## 约束

- 不引入第三方依赖。
- 保持现有公开 API，除非题面明确允许调整。
- 考虑输入校验、边界条件和确定性行为。
- 只修改必要文件；不要读取或猜测隐藏测试。
- 可用工具时先检查 仓库中的 Python 源码，完成后运行公开测试（若存在）。
- 最终修改必须留在工作区；非工具模式下输出统一 diff。
