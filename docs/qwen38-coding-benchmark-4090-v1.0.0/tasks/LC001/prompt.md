# 长仓库权限通配符与拒绝优先级

你正在维护一个仅使用 JDK 标准库的 Java 17+ 小型工程。请在仓库内完成修复或实现。

## 任务

大型仓库中权限检查出现回归：`project:*` 无法授权 `project:read`，同时显式 deny 应覆盖 allow。请定位权限解析链并修复：权限大小写不敏感、去首尾空白；支持全局 `*`、命名空间 `prefix:*` 和精确匹配；以 `!` 开头的 grant 为 deny，任何匹配 deny 都优先返回 false。非法输入应拒绝。不要修改无关 domain 组件。

## 约束

- 不引入第三方依赖。
- 保持现有公开类名和方法签名，除非题面明确允许调整。
- 处理边界条件、异常语义和并发要求。
- 只修改必要文件；不要读取或猜测隐藏测试。
- 可用工具时先检查 整个仓库，优先使用 search 定位 security/permission 相关实现，完成后运行公开测试（若存在）。
- 最终修改必须留在工作区；非工具模式下输出统一 diff。
