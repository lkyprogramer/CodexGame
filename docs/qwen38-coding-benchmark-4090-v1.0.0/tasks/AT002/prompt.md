# 定位 CLI 显式 false/0 被忽略问题

你正在维护一个只依赖 Python 3.11+ 标准库的工程。请在仓库内完成修复或实现。

## 任务

CLI 用户显式传入 `--no-debug` 或端口 0 时，配置合并错误地回退到了低优先级值。修复配置解析：优先级 defaults < file < env < cli；只有 `None` 表示“未提供”，False、0、空字符串均是显式值。未知配置键抛出 `ValueError`，输入 dict 不得修改。

## 约束

- 不引入第三方依赖。
- 保持现有公开 API，除非题面明确允许调整。
- 考虑输入校验、边界条件和确定性行为。
- 只修改必要文件；不要读取或猜测隐藏测试。
- 可用工具时先检查 整个仓库并运行 `python3 public_tests.py`，完成后运行公开测试（若存在）。
- 最终修改必须留在工作区；非工具模式下输出统一 diff。
