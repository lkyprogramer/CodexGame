# 多 SKU 库存预留原子性

你正在维护一个仅使用 JDK 标准库的 Java 17+ 小型工程。请在仓库内完成修复或实现。

## 任务

修复 `InventoryReservationService.reserve(Map<String,Integer>)`。所有 SKU 的数量必须为正；先在同一 `InventoryRepository.transaction` 中读取并验证全部库存，再执行扣减。任一 SKU 不存在或库存不足时，整个操作无写入。相同 SKU 只处理一次，输入 map 不得被修改。成功返回扣减后的不可修改库存快照。禁止在事务外读写。

- 处理边界条件、异常语义和并发要求。

- 可用工具时先检查 仓库和事务接口相关源码，完成后运行公开测试（若存在）。
