# RFC 6901 JSON Pointer 读取

你正在维护一个只依赖 Python 3.11+ 标准库的工程。请在仓库内完成修复或实现。

## 任务

实现 `json_pointer_get(document, pointer, default=_MISSING)`。

遵循 RFC 6901：空指针返回根对象；非空指针必须以 `/` 开头；token 中 `~1` 解码为 `/`、`~0` 解码为 `~`，其他 `~` 转义非法。字典按字符串 key 查找；列表只接受 `0` 或无前导零的十进制下标，`-` 非法。不存在时：提供 default 就返回 default，否则抛出 `KeyError`；指针语法非法抛出 `ValueError`。
