# 定位月末调度崩溃

你正在维护一个只依赖 Python 3.11+ 标准库的工程。请在仓库内完成修复或实现。

## 任务

公开测试显示每月 31 日任务在二月崩溃。修复 `next_monthly(after, day)`：返回严格晚于 after 的下一次月度日期；若目标月份没有该日，钳制到该月最后一天。若本月钳制后的日期仍晚于 after，应返回本月，否则下月。day 只能为 1..31。

## 约束

- 不引入第三方依赖。
- 保持现有公开 API，除非题面明确允许调整。
- 考虑输入校验、边界条件和确定性行为。
- 只修改必要文件；不要读取或猜测隐藏测试。
- 可用工具时先检查 整个仓库并运行 `python3 public_tests.py`，完成后运行公开测试（若存在）。
- 最终修改必须留在工作区；非工具模式下输出统一 diff。
