# 严格时长表达式解析器

你正在维护一个只依赖 Python 3.11+ 标准库的工程。请在仓库内完成修复或实现。

## 任务

实现 `parse_duration(text: str) -> int`，返回毫秒数。

合法单位按从大到小排列：`d`、`h`、`m`、`s`、`ms`。每个单位最多出现一次，允许省略单位，例如 `1h30m`、`2m5s250ms`、`500ms`。组件必须是非负整数，最终总时长必须大于 0。

拒绝空白、浮点数、未知单位、重复单位、顺序倒置、残留字符和纯零表达式，统一抛出 `ValueError`。非字符串也抛出 `ValueError`。

## 约束

- 不引入第三方依赖。
- 保持现有公开 API，除非题面明确允许调整。
- 考虑输入校验、边界条件和确定性行为。
- 只修改必要文件；不要读取或猜测隐藏测试。
- 可用工具时先检查 仓库中的 Python 源码，完成后运行公开测试（若存在）。
- 最终修改必须留在工作区；非工具模式下输出统一 diff。
