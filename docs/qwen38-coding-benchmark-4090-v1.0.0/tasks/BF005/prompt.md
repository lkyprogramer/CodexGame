# 修复 DST 日程计算

你正在维护一个仅使用 JDK 标准库的 Java 17+ 小型工程。请在仓库内完成修复或实现。

## 任务

修复 `DailySchedule.nextAfter`，计算指定时区每天某个本地时间在 `after` 之后的下一次触发：

- 返回值必须严格晚于 after，并使用传入 zone。
- 正常日期使用该本地时间。
- 春季跳时导致本地时间不存在时，使用该 gap 结束后的第一个有效时刻。
- 秋季回拨导致本地时间出现两次时，按时间线选择严格晚于 after 的最早一次；若两次均已过去则看下一天。
- null 参数抛出 `IllegalArgumentException`。
