Autoregressive decoding operates sequentially, generating each token based on the previously generated sequence. On an RTX 4090, this process is primarily memory-bound; because the model weights must be loaded from VRAM for every single token generated, the speed is limited by the GPU's memory bandwidth. While 4-bit quantization reduces the data footprint, the fundamental bottleneck remains how quickly data can move from memory to the processing cores.

In contrast, the diffusion generation process relies on iterative denoising steps. Instead of generating one discrete unit at a time, the model performs multiple passes over the data to refine the output. This makes the process more compute-bound, leveraging the 4090's high TFLOPS.
