    *   *DiffusionGemma*: A hypothetical or specific model combining diffusion-based de-noising with Gemma-like architecture.
    *   *Q4_K_M*: A quantization level (4-bit K-medium), reducing memory usage and increasing speed.
    *   *RTX 4090*: High-end consumer GPU (24GB VRAM, high TFLOPS).
    *   *Autoregressive (AR) Decoding*: Generating tokens one by one. Each step depends on all previous steps. Usually memory-bandwidth bound for small models, compute-bound for large ones.
    *   *Diffusion Generation*: Iterative refinement starting from noise. Usually involves multiple passes (steps of denoising). Often compute-bound if the number of steps is high.

    *   *Autoregressive decoding:*
        *   Mechanism: Sequential.
        *   Complexity: $O(N)$ steps where $N$ is sequence length.
        *   Bottleneck: Memory bandwidth (loading weights for every token generated).
        *   Performance metric: Tokens per second (t/s).

    *   *Diffusion generation:*
        *   Mechanism: Iterative denoising.
        *   Complexity: $O(S \times L)$ where $S$ is the number of denoising steps and $L$ is the resolution.
        *   Bottleneck: Compute power (FLOPs) during each denoising step.
        *   Performance metric: Samples per second or generation time per-step count.

    *   *The Tradeoff:*
        *   AR is better for structured sequences (text) but suffers from latency as sequence length grows.
        *   Diffusion is better for global coherence in high-dimensional data (like images/audio) but requires multiple forward passes, which can be computationally expensive.
        *   On a 4090, the Q4_K_M quantization allows the model to fit easily in VRAM, shifting the bottleneck from memory capacity to compute speed.
