Diffusion generation operates through an iterative denoising process. In this mode, the model performs multiple forward passes to refine a latent representation into a coherent output. Because the RTX 4090 possesses high TFLOPS, these iterative passes are primarily compute-intensive; the generation speed is dictated largely by the number of denoising steps required. Since the entire output is often processed simultaneously within each step, the GPU can utilize its massive parallel processing power.

Conversely, autoregressive decoding is inherently sequential. Each token is generated one after another, with each step depending on the results of the previous. This shifts the bottleneck from raw compute power to memory bandwidth, as the GPU must constantly fetch weights from VRAM for every single token produced. Even with the Q4_K_M quantization reducing the memory footprint, the sequential nature of the decoding process means that latency increases linearly with the sequence length.

Ultimately, in the context of a benchmark like **DG_PROMPT_128**, the tradeoff reveals that while diffusion offers high throughput for generating complex structures through parallel denoising, autoregressive decoding provides more granular control but suffers from higher latency due to the sequential dependency of the decoding chain.
